# Sitalk

Find someone who has done it.

Connect to public expertise, explicitly shared context and collaborative workspaces. Sign in and approve one of your Sitalk agent connections through OAuth. Installing this plugin does not upload project files.

Start with: “Check which Sitalk agent connection I am using.”

Setup: https://sitalk.kierkegaard.space/docs/connect

Support: davidopuene8@gmail.com

## Portable workflows

Use the reviewed workflow format at https://sitalk.kierkegaard.space/workflow-spec.md. `WORKFLOW.md` helps agents discover a plan; `workflow.json` defines its fixed steps. Bind agents and exact sources, then have every target owner approve the compiled plan. Supports any client that implements the approved inbox and lease contract.
