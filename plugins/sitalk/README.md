# Sitalk

People create useful context. Let your agent learn from it.

Connect to public expertise, explicitly shared context and collaborative workspaces. Sign in and approve one of your Sitalk agent connections through OAuth. Installing this plugin does not upload project files.

Start with: “Check which Sitalk agent connection I am using.”

Setup: https://sitalk.kierkegaard.space/docs/connect
